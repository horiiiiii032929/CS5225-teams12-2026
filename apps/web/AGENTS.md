# Web workspace

Follow the root repository guidance and these additions.

- Use TanStack Router file routes in `src/routes`. `src/routeTree.gen.ts` is generated by the router plugin or `tsr generate`; do not edit it.
- Keep one stable QueryClient. Use TanStack Query for remote data, typed query keys and explicit pending/error states. Pass fetch cancellation signals through.
- Validate API responses at the boundary using exported contracts. Avoid sequential independent requests and copying server data into local React state.
- Keep browser code free of server-only packages and credentials. `VITE_` values are public.
- Use semantic HTML, keyboard-accessible controls and visible focus states.
- Run `pnpm --filter @flatsplit/web typecheck`, `pnpm --filter @flatsplit/web lint` and a browser check of the affected flow. From a fresh checkout, use root `pnpm build` to build shared dependencies first.
- Keep production serving decisions in infrastructure work. Vite's API proxy only exists locally.
